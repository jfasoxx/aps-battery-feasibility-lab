# Repository access and local use

Repository: https://github.com/jfasoxx/aps-battery-feasibility-lab

The source, measured public snapshots, synthetic demo, executed notebook and guide
are intended for publication on the public `main` branch. Remote publication is
complete only when those files can be fetched from GitHub.

After the project commit appears online, use **Fetch origin** and **Pull origin**
in GitHub Desktop to bring the files onto your computer. Run the README's setup
commands from that repository folder. Install the notebook requirements if you
want to rerun the reviewer notebook.

The public-data snapshots contain EIA observations, not private APS information.
Do not commit API keys, `.env`, your virtual environment or private project inputs.
Public APS source documents are linked rather than redistributed. Publishing the
repository does not deploy a website or submit an internship application.
